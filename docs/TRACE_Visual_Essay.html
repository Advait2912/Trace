TRACE: Memory in Motion

In-Context Learning with Recurrent Memory — Full Visual Essay
Artifact: Interactive Visual Essay • Dual-Engine Parity Verified (Python × TypeScript) • arXiv Grounded
The Central Falsifiable Claim: A fixed-size recurrent state can absorb an unbounded number of key–value demonstrations without growing in size, but when two demonstrations share overlapping (non-orthogonal) keys, the readout for one leaks the value of the other — a measurable, reproducible form of forgetting caused by fixed capacity, not a scripted failure. In our controlled experiment, increasing the state dimension allows construction of more mutually orthogonal keys and therefore reduces the interference we observe.
Explicit Non-Claim & Scope Boundary: TRACE is an educational toy model instantiating the additive special case named in BDH-CQ §3.2 (Engdahl et al., 2026, arXiv:2608.09888). It does not implement or reproduce proprietary BDH-CQ weights, deep non-linear update networks, or ~5% sparse non-negative synaptic activation vectors. TRACE uses an unconstrained dense linear matrix in ℝd×d to make the mathematical mechanics solvable by hand.

01 / The Hook: Lossless In-Context Memory

Imagine demonstrating three key–value associations to a recurrent model: red → 1.0, blue → 2.0, and green → 3.0. Instead of concatenating tokens into a growing list, the model updates a single, fixed-size 3×3 matrix.

When queried with green, the readout produces 3.0000 with 0.0000 error. The state did not grow by a single byte, yet it retains all three facts with machine precision. This demonstrates the primary thesis: fixed physical memory does not imply inability to absorb sequential context.

02 / Two Ways to Remember Context

Standard Transformer (KV Cache)
  • Mechanism: Concatenates key and value projections for every token into an append-only list.
  • Memory Footprint: O(T) — grows linearly with context length T.
  • Capacity: Lossless key separation via softmax dot-product attention over all past positions.
Recurrent Synaptic Memory (TRACE / BDH-CQ)
  • Mechanism: Ingests demonstrations directly into an evolving internal state tensor St.
  • Memory Footprint: O(1) — exactly d2 scalars, constant for all T.
  • Capacity: Geometrically bounded by state dimension d. When T > d, overlap is inevitable.

03 / The Computational Substrate

The educational substrate instantiates the additive linear attention update rule analyzed in BDH-CQ §3.2 Engdahl et al., 2026; Schlag et al., 2021:

State Initialization: S0 = 0d×d ∈ ℝd×d
Demonstration Update: St = St-1 + vt ktT
Normalized Readout: ŷ = (St · kq) / (kq · kq)

When querying for target key ka after writing T demonstrations, the readout decomposes formally into:

ŷa = va + ∑b≠a [ (ka · kb) / (ka · ka) ] vb

The cross-talk term Interference(ka, kb) = (ka · kb) / (ka · ka) is derived directly from linear algebra. It is neither simulated nor randomized.

04 / Step-by-Step State Evolution (d=3)

Let d = 3, with carrier vector c = [1, 1, 1]T / √3. Orthonormal keys k1, k2, k3 are constructed via QR decomposition:

  • Step 0: Initial state S0 is all zeros (3×3).
  • Step 1: Write red → 1.0 via rank-1 outer product v1 k1T.
  • Step 2: Write blue → 2.0 via v2 k2T. State absorbs new synaptic patterns.
  • Step 3: Write green → 3.0 via v3 k3T. Final state S3 holds all three facts simultaneously.

Because ki · kj = 0 for all i ≠ j, the cross-talk sum vanishes completely, yielding exact zero-error recovery.

05 & 06 / Direct Manipulation & Geometric Capacity

In an unconstrained linear subspace ℝd, the maximum number of mutually orthogonal non-zero vectors is strictly d. This creates an exact capacity threshold:

  • Under-Capacity (N ≤ d): Gram-Schmidt QR decomposition allocates mutually orthogonal vectors. The reconstruction error is MSE ≡ 0.000 down to floating-point precision (10-31).
  • Over-Capacity (N > d): Vectors are forced into linear dependence. Key vectors on the unit sphere Sd-1 must have non-zero inner products, causing measurable value leakage.

07 / Interference from Overlapping Keys (d=2)

To observe interference in isolation, we demonstrate two non-orthogonal keys in d=2:

  • Demonstration A: kA = [1.0, 0.0]T, value = 1.0
  • Demonstration B: kB = [0.6, 0.8]T, value = 9.0

The dot product is kA · kB = 0.60. The leak coefficient is exactly: Interference(kA, kB) = 0.60 / 1.0 = 0.60.

Querying kA after writing both facts yields: ŷA = 1.0 + 0.60 × 9.0 = 6.4000. The readout matches the analytical formula to floating-point tolerance. This distinguishes genuine geometric capacity leakage from arbitrary corruption or same-key overwrites.

08 & 09 / Connections to BDH & BDH-CQ

The Dragon Hatchling Kosowski et al., 2025 (arXiv:2509.26507) proposes that attention can be understood as fast synaptic plasticity. TRACE illustrates this by showing that memory write operations are rank-1 updates to synaptic weights.

BDH-CQ Engdahl et al., 2026 (arXiv:2608.09888) proves that recurrent state models can solve novel symbolic tasks without chain-of-thought tokens. TRACE isolates the exact additive special case (§3.2) to demonstrate how in-context demonstration learning functions mechanically inside a fixed matrix.
